> [!WARNING]
> This is an internal development pre-release, not a release candidate. Bugs, visual differences, performance drops, freezes, and GPU crashes may still occur on real hardware.

**Included build: v0.79-1.** This release merges the public VitaGL line with the Native GXM work that was tested privately after v0.78 (builds v0.78-12 to v0.78-16). The previous development release was [v0.78](https://github.com/WolffsRoom/DeltaruneVita/releases/tag/v0.78).

## Highlights

### Native GXM stability

* Fixed the GPU crashes on room changes in Chapters 2, 3 and 5. Deleted textures were released after four NanoVG flushes instead of four presented frames, so borders and atlases replaced on room entry could be freed while the GPU was still sampling them.
* The main thread now has a 4 MiB stack (GML calls run recursively), and the C heap stays at 128 MiB so textures and surfaces keep enough memory.
* `draw_primitive_*`, vertex colours, textured primitives and `vertex_submit` are implemented. The Chapter 3 videogame minigame no longer aborts with C2-12828-1. Other unsupported states are logged and skipped instead of closing the game.
* Alpha-only write masks are expressed with equivalent blend factors, and the application surface is made opaque before it is shown, as GameMaker does. This fixes the black wall in the Chapter 3 green room.
* Surfaces may be up to 4096 px per side.

### Native GXM features now matching VitaGL

* The per-room DELTARUNE rules that only existed in the VitaGL runner now also run on GXM: the Spanish translation no longer shows a black screen, and the Flowey tower and castle reflections use the reduced update cadence.
* Atlases load from the shared `texture-cache` (`.r444`). When a chapter has no cache yet, it is generated once, with the loading screen and progress bar, before gameplay starts. `gxm-r444-cache.txt` containing `0` disables the cache for testing.
* Native (NP) trophies, the in-game trophy popup, screen filters (Scanlines, Sharp Bilinear, Dithering, VHS), collision masks with the object inspector, Debug DEV captures in `devlogs/chapter N/` and the "New diagnostic log" archive work on GXM.
* PlayStation button prompts, left-stick movement, the Game Over "Give up" exit and VitaGL's border rules (no border before the chapter menu, on menus or on Game Over).
* The Chapter 3 board camera grayscale effect (`shd_grayscalesand`) has a native shader.
* Text line spacing, `\r\n` handling, font scale and ascender offset follow the GL renderers. Snapshots of surfaces keep their colours (no pink text in the Chapter 0 transition), and the opening video uses five decoder buffers.
* New diagnostics in `native-gxm-probe.log`: a stall watchdog, memory telemetry, room entry and first-frame costs, draw-time breakdown and blend variants.

### Chapter 5

* `global.opti_mode` is seeded when a save is loaded past the cliffs, so the final battle no longer skips the tower's draw path.

### Known issues

* The Flowey tower can still be invisible on Native GXM, and changing scenery in the final battle still drops frames.
* Music may not resume after some Chapter 1 battles on Native GXM.
* Some rooms run below the FPS target on Native GXM (Chapter 3 ranking hub and minigames, Chapter 4 `room_dw_castle_tv`).

## Installation

1. Install `Deltarune-v0.79.Internal-Build-Test.vpk` with VitaShell.
2. Keep your prepared game data in `ux0:data/deltarune/deltarunevita/`.
3. Choose VitaGL or Native GXM in Game Settings → Graphics → Graphics API.

## Testing / bug reports

Please include `ux0:data/deltarune/deltarunevita/native-gxm-probe.log` (GXM), `butterscotch-probe.log`, any `psp2core-*.psp2dmp`, the chapter and the room name.
