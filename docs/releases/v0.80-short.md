# DELTARUNE for PS Vita — v0.80 (Concise Release Notes)

**Coverage:** v0.80-1 through v0.80-41 (3 November 2026). Internal development summary, not a completed physical-device certification. Full technical details: [v0.80.md](v0.80.md).

Hey everyone! Wolff here!

v0.80 is a major graphical and performance overhaul since v0.73, featuring the new experimental **Native GXM** renderer, improved loading, a new welcome prologue, and fixes across all five chapters.

## Highlights

- **Native GXM joins VitaGL:** more direct access to the Vita GPU and ongoing shader compatibility. VitaGL is the current startup default; select GXM in Game Settings and restart.
- **GPU stability and graphics:** targeted memory safeguards, improved texture caching, transparency, borders, lighting and demanding room transitions.
- **Loading:** a measured 0–100% progress display, translated stages, smoother animation and selective preloading. Background room preparation in supported paths.
- **New introduction:** an interactive multilingual egg/tree prologue with live text, language icons, controller prompts and audio, now on both graphics backends; refreshed LiveArea and opening-video work.
- **Audio and video:** improved battle music recovery, scene sound effects, CRT rendering, video layering and full-screen Chapter 5 video path.
- **Controls and interface:** refined Game Settings, PS4 button icons, screen adjustment, larger DEBUG overlay and microphone/mouse input for Mike.
- **Room Navigator:** one L + Triangle browser, room names, six rooms per page, safer confirmation, hold L/R for quick paging and current-room hint.

### Internal v0.80-42 follow-up

VitaGL now restores left stick and D-pad movement in Chapter 4 Mike rooms while the right stick and touch operate the pointer. A new Controls slider sets Mike mouse sensitivity (20–200%). CRT Tube is now selectable in VitaGL/Experimental-GL with scanlines, vignette, glass reflection and rounded corners (the GXM barrel deformation is not yet matched). A separate technical note assesses the Chapter 5 XDELTA CRT mod and its cross-chapter limitations. Build and archive checks passed; PS Vita/Vita3K scene verification is still pending.


### Internal v0.80-43 — CRT Mod (Experimental)

New global CRT Mod screen filter for VitaGL Experimental-GL, usable in all Chapters 0–5: barrel curvature, phosphor RGB grille, nine-sample scanlines, analog noise/interference, chromatic aberration, vignette and tracking roll. Based on analysis of the RC_586 Chapter 5 mod. No changes to original game data; fallback to lightweight CRT Tube if unsupported. Build and static checks pass, but physical PS Vita/Vita3K visual/FPS verification remains pending.


### Internal v0.80-44 — Animated Borders

Added animated borders option alongside Better borders when console borders are Dynamic. Five Enhanced border sets preprocessed to native 960x544 RGB/A4444 streams in mods/bordersanim; preserves original GIF frame pacing without decoding GIF on device. One reusable GPU texture; static fallback on unavailable animation. Separate zip assets package. VitaGL only; GXM remains unchanged. PS Vita runtime QA pending.


### Internal v0.80-45 — CRT Mod crash mitigation

Addressed CRT Mod Experimental-GL crashes reported with two PS Vita dumps: cut shader complexity to three texture fetches while retaining the main analog CRT treatments, added stage-by-stage pipeline diagnostics and a one-restart safe CRT Tube fallback if initialization crashes again. Builds and source regressions pass; device verification pending.


### Internal v0.80-46 — CRT Mod and Animated Border performance

CRT Mod now uses a subtle zero-framebuffer-readback overlay, without UV zoom; applies before game UI. Better borders is a single 3-way option (Off / Default / Animated), including config migration. Native-resolution 960x544 mod frames preserved; playback uses 480x272 fast streams to cut upload and IO 75%, with persistent file handles. VitaSDK builds and four source regression tests pass; physical Vita benchmarking pending.


### Internal v0.80-47-ch12 — Chapters 1 and 2: audio, mice, towers and Castle Town

Music now comes back after loading a save, and Castle Town's missing texture page is rebuilt once from the game data instead of staying blank. Mice no longer vanish on Noelle: one collision event fires per pair and a local anti-softlock guard stopped interfering, which is also the probable fix for the third mouse puzzle's towers. Audio handles and stream pitch were corrected. Silence in `room_legend` and the chase rooms and the Sweet Cap'n Cakes music are still unexplained, so diagnostics were added. VitaGL only; build and static checks pass, PS Vita/Vita3K testing is pending.


### Internal v0.80-47-ch5 — Chapter 5 platform-room crashes and final battle

Native GXM no longer runs out of render targets while loading Flower Castle platform rooms, the confirmed cause of crash C2-12828. VitaGL disables the palette shader in those rooms, the probable cause of their GPU crash, so palette-swapped sprites keep their original colors there. The final battle gains a RAM page cache and shorter texture retry delays to reduce stutter and missing textures. Build and static checks pass; PS Vita/Vita3K testing is pending.

### Internal v0.80-47-ch4 — Chapter 4 climb lock, tower lag and School transition

Room Navigator clears the control lock; `draw_sprite_tiled` clips on surfaces; towers visit 432 of 6467 tiles per frame; the School to Castle Town border fade no longer restarts every frame. Tested on PC and statically only, not on PS Vita. See [ch4-climb-tower-transition-v0.80-47.md](../ch4-climb-tower-transition-v0.80-47.md).

### Internal v0.80-47-bordas — Animated borders, CRT Mod and chapter load time

Animated borders now read and copy frames on a background thread and draw only the side columns, at native 960x544 instead of 480x272. Any border with a folder in the mod animates. CRT Mod restores all the GL state it changes, its scanlines now actually appear, and its fallback stays under the GUI. Chapter loading no longer reads the image and sound data of `data.win` just to get their tables (4 to 6 times faster on a PC; not measured on a Vita). VitaGL only. Not yet run on a PS Vita or Vita3K.


### Internal v0.80-47-ch5b — New palette shader and Flower Castle performance

The previous build stopped the GPU crashes on PS Vita, according to the tester. This build replaces the palette shader's per-pixel search with a lookup table, restoring recolored sprites at a fixed cost. Large Flower Castle surfaces use less VRAM, and the reflection pass refreshes less often. Build and static checks pass; this build has not been tested on PS Vita or Vita3K.
